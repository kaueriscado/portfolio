Sí, en vivo los martes a las 17h Colombia / 19h Brasil. Todas quedan grabadas y disponibles para ver a tu ritmo.

Mínimo 3-4 horas: 90 min de clase + 2 horas para el desafío semanal. El programa está diseñado para creadoras con otras responsabilidades.

Sí. El método funciona para cualquier nicho: belleza, moda, gastronomía, fitness, educación, lifestyle, diseño, emprendimiento. Los principios son universales.

No. El 84% de nuestras alumnas tienen menos de 5.000 seguidores. El programa está diseñado para creadoras que están empezando o profesionalizando.
